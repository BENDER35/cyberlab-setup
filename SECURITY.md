# Uso responsable / Responsible use

Este proyecto instala herramientas de ciberseguridad de uso general. La mayoria
son de doble uso: sirven tanto para defender como para probar sistemas.

**Regla obligatoria:** solo utiliselas en equipos, redes o aplicaciones de su
propiedad, o para las que tenga autorizacion por escrito del propietario.

## Permitido / Allowed

- Laboratorio aislado en casa (VM, contenedores Docker, redes de invitados).
- Escaneos contra su propio router, PCs o VMs.
- Practicar con DVWA, OWASP Juice Shop, Metasploitable, etc., en red interna.
- Analizar archivos que usted mismo ha creado o descargado de fuentes de confianza.

## No permitido / Not allowed

- Escanear o atacar redes de terceros (vecinos, universidad, trabajo, Internet publico).
- Usar credenciales reales o datos personales ajenos.
- Ejecutar malware en el equipo anfitrion o propagarlo.
- Evadir la ley aplicable o las politicas de su organizacion.

## Reportar un problema / Reporting a vulnerability

Abra un issue privado en GitHub (<https://github.com/BENDER35/cyberlab-setup/security/advisories>)
o escriba al autor. No publique detalles explotables en issues publicos.

---

This project installs general-purpose cybersecurity tools. Most are dual-use.
**Rule:** only use them on systems you own or have explicit written permission
to test. Do not scan or attack third-party networks. Report vulnerabilities
privately through GitHub Security Advisories.
